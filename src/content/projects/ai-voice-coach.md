As founding engineer at MakeTimeFlow, I'm leading the development of v2 of the company's core product: a voice-enabled AI coaching agent that helps professionals manage their time and focus through natural conversation.

The agent integrates Claude for reasoning and conversation management with ElevenLabs' real-time speech API for voice interaction. I'm designing multi-turn conversation management with persistent user context and session state, allowing the agent to reference previous coaching sessions, track commitments, and adapt its approach based on each user's patterns. I also built a REST API enabling integration between the AI agent, Claude Code, and external agent workflows.

This feature became the product's core differentiator after resonating strongly in paid user interviews. The positive response drove a strategic pivot, shifting the team from a general-purpose SaaS tool toward AI-native positioning built around the voice coaching experience.

Beyond the AI agent, I drive the full product lifecycle in close collaboration with the CEO on our three-person team: customer research, product strategy, architecture, and deployment. I drove the pivot from $30/month consumer subscriptions to $3,000 enterprise contracts based on insights from user research, re-architected the calendar integration system to support real-time webhook sync across multiple providers with an integration-agnostic service layer, and built AI-augmented development workflows (custom Claude Code skills, worktree automation for parallel coding agents) adopted across the dev team.
